# トーンマッピンググロー
AviUtl2用のグローシェーダーです　これ1つで従来のグロー処理からT光までできます\
以下項目説明\
モード:レイヤーそのものにグロー処理をかけるかレイヤーのグロー処理の結果をフレームバッファに合成する(T光的処理)かを選ぶことができます\
半径:グローの半径を操作します\
角度:グローの角度を変えることができます\
露出_マスク:どこまで強く光らせるかを決めることができる項目の1つです\
露出_全体:レイヤー全体の明るさを決めます　フレームバッファにレイヤーのグローを合成モードの時に暗すぎる場合はここを上げて下さい\
マスク:どこまで暗い光度までグローさせるかを決めることができます　光合成など、グローさせるレイヤーが白一色などといった場合は意味がありません\
マスクの滑らかさ:これが高いと光度が低い部分は影響が少ない形でグローさせることができます\
彩度の影響:0より高いと彩度が高い色を優先的に光らせることができます　低いと逆に彩度が高い色は光りづらくなります

半径_クロスブラー:クロスブラーの半径を決めることができます\
光条数:クロスブラーの線の数を決めることができます\
コントラスト:クロスブラーの光の強さを個別で決めることができます\
全体角度:クロスブラーの光の全体の角度を決めることができます　360度なら全体に回り0度なら一方向にしか光りません\
光の急峻さ:どこまで強く光らせるかを決めることができる項目の1つです　こちらは中心近くが強く光るようになります\
中心部分強度:更に中心近くに絞って光が強くなります

元画像の明度で減光:フレームバッファにレイヤーのグローを合成モードの場合、フレームバッファの明度が高い場合そこにかかるグローが白飛びしにくくなります\
合成調整_グロー強度:どこまで強く光らせるかを決めることができる項目の1つです\
トーンマップ1:上げるとグロー以外の周囲を暗くしてよりグロー部分が明るく見えるようになります\
トーンマップ2:トーンマップ1と同様ですが、こちらは上げても彩度が損なわれません　1と併せて使ってください

その他は光の色を変えることができます　スライダーと併せると光の色をアニメーションさせることができます

合成調整_グロー強度は露出_マスクと役割が被っているので廃止するかもしれません　廃止してほしくないなどの意見があればお願いします
